# UI kit · Plataforma web

Recorrido de tres pantallas construido **solo** con los componentes de `components/`:

| Pantalla | Archivo | Contenido |
| --- | --- | --- |
| Inicio | `Home.jsx` | NavBar, hero, rejilla de seis materias, CTA docentes, footer |
| Materia | `Materia.jsx` | Cabecera teñida con el color de la materia, Tabs (Lecciones / Práctica / Progreso), lista de lecciones |
| Lección | `Leccion.jsx` | Barra de progreso, enunciado, campo de respuesta monoespaciado, Alert de corrección, hueco del widget |

`index.html` los enlaza con navegación real: inicio → materia → lección → volver.

Los huecos rayados en azul son **placeholders de captura/ilustración**: no hay imágenes reales en el sistema todavía.
