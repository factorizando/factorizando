Botón de acción; úsalo para cualquier acción tocable, con una sola variante `primary` por pantalla.

```jsx
<Button variant="primary" size="lg">Empezar gratis</Button>
```

Variantes: `primary` (azul #0056D2), `secondary` (tinte azul claro), `tertiary` (contorno neutro), `success` (azul #1B8ACB, para "Comprobar respuesta"), `onDark` (blanco sobre navy). Tamaños sm/md/lg = 40/46/54px; en flujos de primaria usa `lg`.
